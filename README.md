# Карточка игрока D&D (локальный сервер)

Проект — локальный сайт для ведения карточек персонажей D&D. Данные хранятся в JSON, вход по логинам, роли: администратор и игроки.

## Быстрый старт

1. Установите зависимости:

```bash
npm install
```

2. Запустите сервер:

```bash
npm run start
```

Сервер будет доступен по адресу: [http://localhost:3000](http://localhost:3000).

## Доступ из локальной сети (LAN/Wi‑Fi)

По умолчанию сервер слушает все сетевые интерфейсы, поэтому его можно открыть с других устройств в той же сети:

```
http://<LAN-IP-вашего-пк>:3000/
```

Например: `http://192.168.1.50:3000/`.

При запуске сервер печатает в консоли:
- LAN IP компьютера.
- Готовую ссылку для открытия с телефона.

### Возможные проблемы

- Убедитесь, что телефон/ноутбук в той же Wi‑Fi сети и отключена изоляция клиентов (Client/AP Isolation).
- Если используется Windows Defender Firewall: разрешите входящие TCP‑соединения на порт 3000 для Private network.
- На Linux при необходимости откройте порт через `ufw`/`iptables`.

## Данные и хранение

- `data/users.json` — логины пользователей и роли.
- `data/characters.json` — карточки персонажей.
- `data/portraits/` — портреты персонажей (PNG). Имя файла: `<id>.png`, иначе используется `default.png` (добавьте его вручную).

По умолчанию создаётся администратор:

- **Логин:** `admin`
- **Пароль:** `admin123`

> Рекомендуется поменять пароль сразу после запуска, вручную отредактировав `data/users.json`.

## Сценарии использования

### Админ

1. Входит под логином `admin`.
2. Создаёт логины игроков в админ-панели (логин + пароль).
3. Видит список «ячеек персонажей»:
   - заблокированные — «Заблокировано / пусто»;
   - неактивные — «Не активен»;
   - активные — «В игре»;
   - удалённые — «Удалён».
4. Может открыть карточку любого заполненного персонажа и вернуться обратно в список.
5. Может фильтровать список: все (кроме удалённых), в игре, не активные, удалённые.
6. Может удалять персонажей (только если не активны). Удалённые можно очистить одним действием.

### Игрок

1. Входит по логину, созданному админом.
2. При первом входе заполняет форму карточки.
3. После сохранения видит карточку своего персонажа.

## Поля карточки

- Имя персонажа
- Раса
- Класс
- Возраст
- Рост
- Внешность
- Особые черты
- Основное оружие
- Используете магию? + сферы (атака, защита, поддержка, особые умения)
- Дополнительная информация

## Примечания

Проект ориентирован на вертикальный экран телефона. Сейчас реализована логика и базовые формы без полноценного дизайна карточки.
